# AI Observatory

Run locally:

```sh
sf dev
```

Deploy:

```sh
sf publish
```

The starter app includes:

- `/`: live guestbook messages, built with the platform kit (`@spacefast/zero/kit`).
- `/about`: a static route rendered by the client router.
- `/api/messages/count`: an endpoint that returns the message count.

`AGENTS.md` is the guide for coding agents working in this capsule.
